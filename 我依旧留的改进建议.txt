① 高德 Key 是空的 → 公交全程“离线演示”

config.js 里 amapKey: ''，所以 planTransitTrip() 必然走 no-key 分支，页面打出“离线演示”标签。评委选“公交地铁”看到的是假线路 —— 评分表第三项“核心流程是否走得通”直接废掉。

- 去高德开放平台申请 Web 服务 Key（个人免费额度够用，5 分钟）
- 控制台里配 域名白名单，否则线上 Key 会被盗刷
- 待办里写了“未验证真实高德返回后的缓存写入”——填 Key 后必须真跑一次

② 自驾、步行根本没有路线

三种模式里，只有公交有真路径：

┌──────┬─────────────────────────────────────────┐
│ 模式 │             现在实际有什么              │
├──────┼─────────────────────────────────────────┤
│ 公交 │ 高德路线（无 Key 时演示线路）+ 到站提醒 │
├──────┼─────────────────────────────────────────┤
│ 自驾 │ 只有“附近加油站”，没有 A→B 路径         │
├──────┼─────────────────────────────────────────┤
│ 步行 │ 只有天气，没有路径                      │
└──────┴─────────────────────────────────────────┘

评委选“自驾”会发现地图上只有两个点和一堆加油站。

最省事的补法：自驾接 OSRM 公开服务，免 Key，纯 GET：

const url = `https://router.project-osrm.org/route/v1/driving/${o.lng},${o.lat};${d.lng},${d.lat}?overview=full&geometries=geojson`;

返回的 routes[0].geometry.coordinates 是 [lng,lat] 数组，直接塞给 L.polyline。二十分钟能接完。
步行没有免费公共路由，就老实做直线虚线 + 1.2 m/s 估算，并在文案里写“步行距离为直线估算”，比空着强。

③ “离线缓存”这个说法过头了

map.html 断网时显示“网络已断开 · 正在使用本地缓存”，但实际：

- 底图瓦片来自 openstreetmap.de / osm.fr —— 断网就白屏
- Tailwind、Leaflet、Google Fonts 全在 CDN —— 断网就无样式无地图
- 缓存只在 sessionStorage —— 关标签页就没

真断网打开，用户看到的是空白页，跟文案承诺完全相反。两条路选一条：
- 要么上 Service Worker 预缓存关键资源（做不完整就别做）
- 要么把文案改成“数据缓存：断网时可显示上次查到的加油站/天气”，别用“离线”这个词

三、体验层（性价比最高的几处）

1. 首页加 2–3 个示例目的地，一键填入：试试：虹桥火车站。评委不知道你想让他输什么，这是全场最大的一处摩擦，改一行 HTML 就能解决。
2. 目的地解析加兜底。只用 photon 一个源，中文地名命中率一般（“虹桥火车站”能不能出来，实测过吗）。加 Nominatim 当第二源，再放一张 10 条常用地点的本地映射表。
3. 到站提醒在电脑上“没反应”。振动和语音在桌面浏览器基本无效。demo 前先点一下“试一下提醒”预热语音权限，否则评委看到横幅闪一下就没了。
4. 老 iOS Safari 会炸。AbortSignal.timeout 在 Safari 16 之前不存在，net.js 第 9 行、gas.js 第 17 行都会直接抛错。手机 demo 前先确认机型。
